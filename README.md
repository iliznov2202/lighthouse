# Маяк

Frontend MVP приложения для учеников 7–11 классов. «Сделано для школьника, а не школы».

React 19 + TypeScript + Vite. Все данные локальные, без backend, базы данных, реальных API и внешних сервисов. Иконки — Lucide; иллюстрации и аватары — встроенные SVG. Цвета и знак вдохновлены предоставленным логотипом, оригинал находится в `public/logo-reference.png`.

## Запуск

```sh
npm install
npm run dev
```

Открыть http://127.0.0.1:5173. На первом экране можно пройти onboarding или выбрать «Заглянуть в демо 9Б».

```sh
npm run build
npm run preview
```

## Публикация на GitHub Pages

В репозитории откройте Settings → Pages → Build and deployment → Source и выберите GitHub Actions.
Отправьте изменения в ветку `main`. Workflow `.github/workflows/deploy.yml` соберёт приложение и опубликует папку `dist`.
Дождитесь успешного завершения «Deploy to GitHub Pages» во вкладке Actions; рабочий адрес появится в Settings → Pages.
Путь к сайту определяется автоматически настройками Pages, включая адрес вида `/lighthouse/`.

Для локальной проверки сборки с этим путём в PowerShell:

```powershell
$env:VITE_BASE_PATH='/lighthouse/'
npm run build
npm run preview
```

Откройте http://127.0.0.1:4173/lighthouse/.

## Возможности MVP

- Onboarding: поиск среди четырёх демо-школ, имя, класс с 7-го по 11-й и буква класса.
- Нижняя навигация на мобильном и боковая на desktop: лента, учёба, создание, уведомления, профиль.
- Лента класса и школы, поиск, обычные и анонимные посты, лайки, комментарии, сохранённое.
- Учёба: «Сегодня», расписание на пять дней, домашка с датами, отметками выполнения и оценкой времени.
- Ручное добавление домашки и имитация распознавания по фото. Фото JPG, PNG, WebP до 8 МБ остаётся в браузере; есть сценарий без файла.
- Импорт недельного расписания: имитация обработки, проверка и редактирование предметов и кабинетов, сохранение недели.
- Утренний и вечерний дайджесты: подготовленные тексты с подстановкой расписания и состояния домашки.
- AI-репетитор: подготовленные объяснения квадратных уравнений, ускорения и сложных предложений, анимация ответа, история диалога. Для других тем честно показывает границы демо.
- Уведомления с прочитанными состояниями, профиль с редактированием, локальные настройки и сброс демо.

## Демо-данные и хранение

Исходный класс — 9Б, школа № 57. Демо-день: **30 сентября 2026**, неделя 28 сентября — 2 октября. «Сейчас» в расписании — фиксированное демо-состояние, часы в дайджестах — примеры. При выборе другого класса используются те же подготовленные демо-данные.

Состояние сохраняется в `localStorage` под ключами `mayak-…-v1`. Закрытие и перезагрузка страницы не стирают изменения. «Профиль → Начать демо заново» восстанавливает исходные данные. Изображения не отправляются и не сохраняются в localStorage; object URL освобождается после закрытия загрузки. Push-настройки демонстрационные, реальная доставка уведомлений не подключена. Анонимные публикации скрывают имя и аватар в интерфейсе; это демонстрация, а не серверная гарантия анонимности.

## Структура

```text
src/
  App.tsx                  # состояние, навигация, оболочка и модальные сценарии
  types.ts                 # доменные типы
  styles.css               # токены, компоненты, адаптивность
  data/mock.ts             # школа, 9Б, расписание, задания, посты, AI-ответы
  hooks/useStoredState.ts  # локальное хранение
  components/
    ui.tsx                 # знак, аватары, кнопки, метки, модальные окна
    Onboarding.tsx
    Feed.tsx
    Study.tsx              # сегодня, неделя, домашка, репетитор, дайджесты
    Composer.tsx           # создание постов, домашки и импорт по фото
    Personal.tsx           # уведомления, профиль, настройки
tests/app.spec.ts          # мобильные и desktop-сценарии Playwright
```

Дизайн-система: глубокий синий текст, белые поверхности, фиолетовый акцент, голубые и розовые мягкие градиенты, радиусы 11–24 px, цвета предметов. От 760 px появляется мобильная нижняя навигация; на tablet скрывается дополнительная колонка. Учтены safe area, клавиатурный фокус, закрытие модальных окон по Escape, удержание фокуса и reduced motion.

## Проверки

```sh
npx playwright install chromium
npm test
```

Можно использовать установленный Chrome: в PowerShell `$env:PLAYWRIGHT_CHANNEL='chrome'`, затем `npm test`.

Тесты проходят onboarding, социальные действия и сохранение после перезагрузки, импорт и редактирование расписания, оба способа добавления домашки, AI-ответы, дайджесты, уведомления и профиль. Запускаются на desktop и мобильном viewport, дополнительно проверяют отсутствие горизонтального переполнения при ширине 320 px. Скриншоты сохраняются в `artifacts/`.
